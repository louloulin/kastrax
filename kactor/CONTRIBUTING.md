# 贡献指南

感谢您考虑为 ProtoActor-Kotlin 做出贡献！以下是一些指导原则，帮助您开始。

## 报告问题

如果您发现了 bug 或有功能请求，请在 GitHub 上创建一个 issue。请尽可能详细地描述问题，包括：

- 问题的详细描述
- 重现步骤
- 预期行为
- 实际行为
- 环境信息（操作系统、JDK 版本等）

## 提交代码

1. Fork 仓库
2. 创建一个新的分支
3. 进行更改
4. 运行测试确保所有测试通过
5. 提交 Pull Request

### 代码风格

- 遵循 Kotlin 官方代码风格指南
- 使用 4 个空格缩进
- 使用有意义的变量名和函数名
- 添加适当的注释和文档

### 测试

- 为新功能添加单元测试
- 确保所有测试通过
- 尽可能提高代码覆盖率

## 兼容性

ProtoActor-Kotlin 与 ProtoActor-Go 兼容，因此在进行更改时，请确保：

- 不破坏与 ProtoActor-Go 的兼容性
- 更新协议定义时同步更新两个实现
- 添加跨语言测试以验证兼容性

## 文档

- 更新相关文档以反映您的更改
- 添加示例代码以展示新功能的用法
- 确保文档清晰易懂

## 许可证

通过提交代码，您同意您的贡献将根据项目的 Apache License 2.0 许可证进行许可。
