# kastrax-code 模块修复计划 (24.md)

## 1. 问题分类

根据执行gradle build -x test命令的结果，我将问题分为以下几类：

### 1.1 JsonPrimitive.getContent 相关问题

1. [x] **getContent方法未找到**：
   - 错误信息：`Unresolved reference 'getContent'`
   - 文件：KastraxCodeAgentImpl.kt, CodeExplanationAgent.kt, CodeRefactoringAgent.kt, TestGenerationAgent.kt
   - 原因：可能是kotlinx.serialization库版本不兼容，或者API变更
   - 解决方案：将context.getContent()替换为context.toString()

### 1.2 CodeContextEngineImpl 相关问题

1. [x] **参数不匹配**：
   - 错误信息：`No parameter with name 'options' found`, `Argument type mismatch`
   - 文件：CodeContextEngineImpl.kt
   - 原因：CodeContextEngineImpl类的方法签名与调用不匹配
   - 解决方案：添加兼容性属性，将配置参数映射到内部属性

2. [x] **类型转换问题**：
   - 错误信息：`Argument type mismatch: actual type is 'ai.kastrax.codebase.semantic.model.CodeElement', but 'kotlin.String' was expected`
   - 文件：CodeContextEngineImpl.kt
   - 原因：API变更导致类型不兼容
   - 解决方案：改进类型转换逻辑，增加错误处理

3. [x] **重复声明**：
   - 错误信息：`Redeclaration: data class CodeContextEngineConfig : Any`
   - 文件：CodeContextEngineImpl.kt, KastraxCodeContextEngine.kt
   - 原因：同一个类在多个文件中定义
   - 解决方案：删除CodeContextEngineImpl.kt中的重复定义，使用KastraxCodeContextEngine.kt中的定义

### 1.3 KastraxCodeContextEngine 相关问题

1. **日志库问题**：
   - 错误信息：`Unresolved reference 'oshai'`, `Unresolved reference 'KotlinLogging'`
   - 文件：KastraxCodeContextEngine.kt, CodeIndexManager.kt, FileSystemMonitor.kt, GitBranchMonitor.kt, IncrementalIndexer.kt, IndexStatusService.kt, CodeMemorySystemImpl.kt, LongTermMemory.kt, MidTermMemory.kt, ShortTermMemory.kt
   - 原因：缺少日志库依赖或导入错误

2. **配置参数问题**：
   - 错误信息：`Unresolved reference 'enableCodeRelationAnalysis'`, `No parameter with name 'enableDistributedIndexing' found`
   - 文件：KastraxCodeContextEngine.kt
   - 原因：配置类的属性名称变更或缺失

3. **依赖问题**：
   - 错误信息：`Cannot access class 'ai.kastrax.store.VectorStore'`, `Cannot access class 'ai.kastrax.store.embedding.EmbeddingService'`
   - 文件：KastraxCodeContextEngine.kt
   - 原因：缺少依赖或包路径变更

### 1.4 CodeMemorySystemImpl 相关问题

1. **抽象方法未实现**：
   - 错误信息：`Class 'CodeMemorySystemImpl' is not abstract and does not implement abstract member 'retrieveProjectMemory'`
   - 文件：CodeMemorySystemImpl.kt
   - 原因：接口变更但实现类未更新

2. **方法参数不匹配**：
   - 错误信息：`No parameter with name 'filePath' found`, `No value passed for parameter 'path'`
   - 文件：CodeMemorySystemImpl.kt
   - 原因：方法签名变更但调用未更新

3. **类型转换问题**：
   - 错误信息：`Argument type mismatch: actual type is 'ai.kastrax.code.memory.CodeMemorySystemImpl.SimpleMessage', but 'ai.kastrax.memory.api.Message' was expected`
   - 文件：CodeMemorySystemImpl.kt
   - 原因：类型不兼容

### 1.5 CodeToolRegistry 相关问题

1. **tool函数使用问题**：
   - 错误信息：`Argument type mismatch: actual type is 'kotlin.String', but 'kotlin.Function1<ai.kastrax.core.tools.ToolBuilder, kotlin.Unit>' was expected`
   - 文件：CodeToolRegistry.kt
   - 原因：tool函数的使用方式错误

2. **DSL语法问题**：
   - 错误信息：`Unresolved reference 'id'`, `'val' cannot be reassigned`, `Unresolved reference 'description'`
   - 文件：CodeToolRegistry.kt
   - 原因：DSL语法使用错误

### 1.6 UI组件相关问题

1. **JBPanel构造函数问题**：
   - 错误信息：`None of the following candidates is applicable: constructor<T : (JBPanel<JBPanel<*>!>..JBPanel<*>?)>(p0: LayoutManager!): JBPanel<T>`
   - 文件：EnhancedChatPanel.kt
   - 原因：构造函数参数不匹配

2. **组件方法未找到**：
   - 错误信息：`Unresolved reference 'layout'`, `Unresolved reference 'border'`, `Unresolved reference 'add'`
   - 文件：EnhancedChatPanel.kt
   - 原因：可能是继承关系错误或导入问题

3. **组件属性未找到**：
   - 错误信息：`Unresolved reference 'componentCount'`
   - 文件：EnhancedChatPanel.kt
   - 原因：属性名称错误或类型不匹配

### 1.7 索引相关问题

1. **导入问题**：
   - 错误信息：`Unresolved reference 'config'`, `Unresolved reference 'event'`
   - 文件：CodeIndexManager.kt
   - 原因：缺少导入或包路径变更

2. **类型未找到**：
   - 错误信息：`Unresolved reference 'CodebaseIndexManagerConfig'`, `Unresolved reference 'CodebaseIndexEvent'`
   - 文件：CodeIndexManager.kt
   - 原因：类型不存在或包路径变更

3. **Git相关问题**：
   - 错误信息：`Unresolved reference 'git4idea'`, `Unresolved reference 'GitBranchUtil'`
   - 文件：GitBranchMonitor.kt
   - 原因：缺少git4idea依赖
