# kastrax-code 模块修复计划 (x23.md)

## 1. 问题分类

根据编译错误，我将问题分为以下几类：

### 1.1 Agent 相关问题

1. **CodeAgent 接口实现问题**：
   - DetailLevelDetectorAgent、LanguageDetectorAgent、QueryResponseAgent、TaskClassifierAgent 类未实现 generateCode 抽象方法
   - 错误信息：`Class 'XXX' is not abstract and does not implement abstract member 'generateCode'`

2. **Agent 创建和使用问题**：
   - CodeExplanationAgent、CodeRefactoringAgent、TestGenerationAgent 类中的 Agent 创建方式错误
   - 错误信息：`Unresolved reference 'Agent'`、`Property delegate must have a 'getValue...' method`

3. **AgentContext 相关问题**：
   - AgentContext 类未找到或引用错误
   - 错误信息：`Unresolved reference 'AgentContext'`、`Unresolved reference 'getContent'`、`Unresolved reference 'process'`

### 1.2 LLM 相关问题

1. **LLM 导入和使用问题**：
   - LlmMessage、LlmMessageRole、LlmOptions 等类的导入和使用问题
   - 错误信息：`Unresolved reference 'LlmMessage'`、`Unresolved reference 'LlmMessageRole'`

2. **DeepSeek 相关问题**：
   - DeepSeekModel、deepSeek 等类和函数的导入和使用问题
   - 错误信息：`Unresolved reference 'DeepSeekModel'`、`Unresolved reference 'deepSeek'`

### 1.3 IntelliJ 平台 API 相关问题

1. **IntelliJ 组件类型不匹配**：
   - Project、JBPanel 等类型不匹配
   - 错误信息：`Argument type mismatch: actual type is 'ai.kastrax.code.mock.Project', but 'com.intellij.openapi.project.Project' was expected`

2. **IntelliJ 组件引用问题**：
   - DataManager、getInstance 等方法未找到
   - 错误信息：`Unresolved reference 'DataManager'`、`Unresolved reference 'getInstance'`

### 1.4 内存系统相关问题

1. **CodeMemorySystemImpl 类问题**：
   - 方法参数不匹配、引用未找到
   - 错误信息：`No parameter with name 'xxx' found`、`Unresolved reference 'queryMemories'`

2. **日志相关问题**：
   - oshai 库引用问题
   - 错误信息：`Unresolved reference 'oshai'`

### 1.5 工具相关问题

1. **CodeTool 接口问题**：
   - Tool 接口未找到
   - 错误信息：`Unresolved reference 'Tool'`

2. **CodeToolRegistry 问题**：
   - tool 函数未找到
   - 错误信息：`Unresolved reference 'tool'`

## 2. 修复优先级

根据问题的严重性和依赖关系，我建议按以下优先级进行修复：

1. **高优先级**：
   - Agent 相关问题（Agent 接口、AgentContext 类）
   - LLM 相关问题（LlmMessage、DeepSeek 等）
   - Tool 相关问题（Tool 接口）

2. **中优先级**：
   - 专门化 Agent 实现（CodeCompletionAgent、CodeExplanationAgent 等）
   - IntelliJ 平台 API 问题（Project、JBPanel 等）

3. **低优先级**：
   - 内存系统相关问题
   - UI 组件相关问题
   - 日志相关问题
