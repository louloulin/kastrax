## 最新实现：查询转换和增强机制

我们刚刚完成了查询转换和增强机制的实现，这是 RAG 系统中的一个重要组件，它通过转换和增强用户的原始查询，提高检索的准确性和多样性。

### 核心组件

1. **查询转换器（QueryTransformer）**：
   - 规范化查询转换器（NormalizationQueryTransformer）
   - 同义词查询转换器（SynonymQueryTransformer）
   - 查询分解转换器（DecompositionQueryTransformer）
   - LLM 查询转换器（LLMQueryTransformer）
   - 组合查询转换器（CompositeQueryTransformer）

2. **查询增强检索器（QueryEnhancedRetriever）**：
   - 单一查询模式：使用转换后的单一查询进行检索
   - 多查询模式：使用多个查询变体进行检索，然后合并结果
   - 结果合并策略：交错合并、按分数合并、多样性合并

### 实现细节

1. **查询转换**：
   - 规范化：移除多余的空格和标点符号，转换为小写
   - 同义词扩展：添加同义词或相关术语，生成多个查询变体
   - 查询分解：将复杂查询分解为多个简单查询
   - LLM 重写：使用大型语言模型重写查询以提高检索效果

2. **结果合并**：
   - 交错合并：从每个查询结果中依次选择一个文档
   - 按分数合并：选择分数最高的文档
   - 多样性合并：首先从每个查询中选择最佳结果，然后按分数填充剩余位置

### 集成到 RAG 系统

查询转换和增强机制已经集成到 RAG 系统中，可以通过 `RagProcessOptions` 配置启用：

```kotlin
val results = rag.search(
    "什么是AI",
    limit = 5,
    options = RagProcessOptions(
        useQueryEnhancement = true,
        queryEnhancementOptions = QueryEnhancedRetrieverConfig(
            useMultiQuery = true,
            mergeStrategy = MergeStrategy.DIVERSITY
        )
    )
)
```
