# KastraX RAG 架构文档

本文档描述了 KastraX RAG 模块的架构设计。

## 整体架构

KastraX RAG 模块的架构由以下几个主要部分组成：

1. **文档处理**：负责加载、清理和分割文档
2. **嵌入**：负责生成文本的嵌入向量
3. **存储**：负责存储文档和嵌入向量
4. **检索**：负责从存储中检索相关文档
5. **重排序**：负责重新排序检索结果
6. **上下文构建**：负责构建上下文
7. **图 RAG**：基于图的检索增强生成
8. **评估和优化**：负责评估和优化 RAG 系统

## 模块详解

### 文档处理

文档处理模块负责加载、清理和分割文档。它由以下几个主要组件组成：

- **DocumentLoader**：负责从各种来源加载文档，如文件、目录、数据库等
- **DocumentSplitter**：负责将文档分割成更小的片段，以便更好地进行检索
- **DocumentCleaner**：负责清理文档内容，去除不必要的格式和噪声

文档处理的流程如下：

1. 使用 DocumentLoader 加载文档
2. 使用 DocumentCleaner 清理文档内容
3. 使用 DocumentSplitter 将文档分割成更小的片段
4. 将处理后的文档传递给嵌入模块

### 嵌入

嵌入模块负责生成文本的嵌入向量。它由以下几个主要组件组成：

- **EmbeddingService**：负责生成文本的嵌入向量
- **EmbeddingServiceFactory**：负责创建各种嵌入服务

嵌入的流程如下：

1. 使用 EmbeddingService 生成文档内容的嵌入向量
2. 将文档和嵌入向量传递给存储模块

### 存储

存储模块负责存储文档和嵌入向量。它由以下几个主要组件组成：

- **DocumentStore**：负责存储文档
- **VectorStore**：负责存储嵌入向量
- **DocumentVectorStoreAdapter**：将 VectorStore 适配为 DocumentStore

存储的流程如下：

1. 使用 DocumentStore 存储文档
2. 使用 VectorStore 存储嵌入向量
3. 提供接口供检索模块使用

### 检索

检索模块负责从存储中检索相关文档。它由以下几个主要组件组成：

- **Retriever**：负责从存储中检索相关文档
- **VectorRetriever**：基于向量的检索器
- **KeywordRetriever**：基于关键词的检索器
- **HybridRetriever**：混合检索器，结合向量和关键词检索

检索的流程如下：

1. 使用 EmbeddingService 生成查询的嵌入向量
2. 使用 Retriever 从存储中检索相关文档
3. 将检索结果传递给重排序模块

### 重排序

重排序模块负责重新排序检索结果。它由以下几个主要组件组成：

- **Reranker**：负责重新排序检索结果
- **IdentityReranker**：不进行重排序
- **RelevanceReranker**：基于相关性的重排序器
- **DiversityReranker**：基于多样性的重排序器

重排序的流程如下：

1. 使用 Reranker 重新排序检索结果
2. 将重排序后的结果传递给上下文构建模块

### 上下文构建

上下文构建模块负责构建上下文。它由以下几个主要组件组成：

- **ContextBuilder**：负责构建上下文
- **ContextBuilderConfig**：用于配置上下文构建过程

上下文构建的流程如下：

1. 使用 ContextBuilder 构建上下文
2. 将上下文传递给 RAG 模块

### RAG

RAG 模块是整个系统的核心，它协调各个模块的工作。它由以下几个主要组件组成：

- **RAG**：检索增强生成系统的主要类
- **RagProcessOptions**：用于配置 RAG 系统的检索和重排序过程

RAG 的流程如下：

1. 接收查询
2. 使用检索模块检索相关文档
3. 使用重排序模块重新排序检索结果
4. 使用上下文构建模块构建上下文
5. 返回上下文和相关文档

### 图 RAG

图 RAG 模块是基于图的检索增强生成系统。它由以下几个主要组件组成：

- **GraphRAG**：基于图的检索增强生成系统的主要类
- **GraphNode**：图节点
- **GraphEdge**：图边
- **GraphRAGConfig**：用于配置 GraphRAG 系统
- **GraphRAGQueryOptions**：用于配置 GraphRAG 查询
- **GraphRAGTool**：GraphRAG 的工具类，提供了更高级的功能

图 RAG 的流程如下：

1. 创建图节点和边
2. 构建知识图谱
3. 接收查询
4. 使用带重启的随机游走算法进行图检索
5. 返回检索结果

### 评估和优化

评估和优化模块负责评估和优化 RAG 系统。它由以下几个主要组件组成：

- **RagEvaluationTool**：用于评估 RAG 系统的性能
- **RagOptimizationTool**：用于优化 RAG 系统的配置
- **RagBenchmarkTool**：用于测试 RAG 系统的性能

评估和优化的流程如下：

1. 使用 RagEvaluationTool 评估 RAG 系统的性能
2. 使用 RagOptimizationTool 优化 RAG 系统的配置
3. 使用 RagBenchmarkTool 测试 RAG 系统的性能

## 数据流

KastraX RAG 模块的数据流如下：

1. **文档加载**：从各种来源加载文档
2. **文档处理**：清理和分割文档
3. **嵌入生成**：为文档生成嵌入向量
4. **存储**：存储文档和嵌入向量
5. **查询处理**：处理用户查询
6. **检索**：从存储中检索相关文档
7. **重排序**：重新排序检索结果
8. **上下文构建**：构建上下文
9. **返回结果**：返回上下文和相关文档

## 扩展点

KastraX RAG 模块提供了多个扩展点，允许用户自定义和扩展系统：

1. **DocumentLoader**：可以实现自定义的文档加载器，支持更多的文档来源
2. **DocumentSplitter**：可以实现自定义的文档分割器，支持更多的分割策略
3. **DocumentCleaner**：可以实现自定义的文档清理器，支持更多的清理策略
4. **EmbeddingService**：可以实现自定义的嵌入服务，支持更多的嵌入模型
5. **VectorStore**：可以实现自定义的向量存储，支持更多的存储后端
6. **Retriever**：可以实现自定义的检索器，支持更多的检索策略
7. **Reranker**：可以实现自定义的重排序器，支持更多的重排序策略
8. **ContextBuilder**：可以实现自定义的上下文构建器，支持更多的上下文构建策略

## 性能考虑

KastraX RAG 模块在设计时考虑了性能因素：

1. **缓存**：使用缓存嵌入服务缓存嵌入向量，减少 API 调用
2. **并行处理**：支持并行处理，提高性能
3. **本地嵌入**：支持本地嵌入服务，减少网络延迟
4. **向量索引**：使用向量索引加速检索
5. **批处理**：支持批量嵌入和检索，减少 API 调用

KastraX RAG 模块在设计时考虑了安全因素：

1. **API 密钥管理**：支持安全的 API 密钥管理

## 实现细节

### 文档处理

文档处理模块使用了以下技术：

- **文本分割**：使用正则表达式和自然语言处理技术分割文档
- **HTML 解析**：使用 Jsoup 解析 HTML 文档
- **PDF 解析**：使用 Apache PDFBox 解析 PDF 文档
- **JSON 解析**：使用 Kotlinx Serialization 解析 JSON 文档

### 嵌入

嵌入模块使用了以下技术：

- **OpenAI API**：使用 OpenAI API 生成嵌入向量
- **Deepseek API**：使用 Deepseek API 生成嵌入向量
- **FastEmbed Kotlin**：使用 FastEmbed Kotlin 库在本地生成嵌入向量
- **缓存**：使用内存缓存和持久化缓存存储嵌入向量

### 存储

存储模块使用了以下技术：

- **内存存储**：使用 HashMap 存储文档和向量
- **Chroma**：使用 Chroma 存储向量
- **Qdrant**：使用 Qdrant 存储向量
- **Milvus**：使用 Milvus 存储向量

### 检索

检索模块使用了以下技术：

- **向量检索**：使用余弦相似度计算向量相似度
- **关键词检索**：使用 BM25 算法计算关键词相似度
- **混合检索**：结合向量检索和关键词检索的结果

### 重排序

重排序模块使用了以下技术：

- **相关性重排序**：使用余弦相似度重新计算相关性
- **多样性重排序**：使用最大边际相关性算法增加结果多样性
- **交叉编码器重排序**：使用交叉编码器模型重新计算相关性

### 图 RAG

图 RAG 模块使用了以下技术：

- **图构建**：使用余弦相似度构建图
- **随机游走**：使用带重启的随机游走算法进行图检索
- **图可视化**：使用 GraphViz 可视化图
