# Kastrax Codebase 实验性功能

本目录包含Kastrax Codebase模块的实验性功能实现，这些功能尚未完全集成到主代码库中。

## 功能列表

1. **代码语义理解**
   - 基于Chapi的代码解析器
   - 符号关系图构建

2. **向量存储优化**
   - 代码特定向量存储
   - 多租户向量存储

3. **上下文感知检索**
   - 多级上下文构建
   - 代码检索模型

## 使用说明

这些功能目前处于实验阶段，API可能会发生变化。在将这些功能集成到生产环境之前，请确保进行充分的测试。
